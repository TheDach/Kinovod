# Kinovod – мобильное приложение для коллективного подбора фильмов

Клиент-серверное Android-приложение для упрощения выбора фильмов и сериалов как для одного пользователя, так и для компании. Приложение позволяет вести личные списки, находить друзей, создавать комнаты для совместного голосования и согласовывать фильм на вечер.

## Описание

**Kinovod** — это мобильное приложение для Android, которое решает проблему долгого и неудобного выбора фильма для совместного просмотра. По данным опроса, 80% пользователей сталкиваются с трудностями при согласовании выбора, а 47% тратят на это от 5 до 15 минут.

Приложение объединяет:
- каталог фильмов с данными из «Кинопоиск API Unofficial»;
- персональные списки «Хочу посмотреть» и «Просмотрено»;
- социальные функции (друзья, общие просмотры);
- комнаты (лобби) для группового голосования с гибкими настройками;
- механику «Тиндер» для поиска совпадений (в перспективе).

Серверная часть проксирует запросы к внешнему API, скрывая токен, и хранит пользовательские данные в MySQL.

## Функциональность

### 🔐 Аутентификация и профиль
- Регистрация и вход по e-mail и паролю.
- Валидация полей, хеширование паролей BCrypt.
- Удаление аккаунта с каскадным удалением всех данных.

### 🎬 Каталог фильмов
- Просмотр каталога с постраничной загрузкой.
- Поиск по названию.
- Фильтрация по:
    - жанрам;
    - типу контента (фильм / сериал);
- Детальная информация о фильме: постер, описание, хронометраж, актёры, рейтинги, трейлеры.

### 📋 Личные списки
- Добавление фильмов в списки «Хочу посмотреть» и «Просмотрено».
- Удаление из списков.
- Просмотр списков в профиле.
- Добавление в друзья и управление списком друзей.

### 🗳️ Комнаты для совместного выбора (лобби)
- Создание комнаты с настройками:
    - название;
    - приглашение друзей;
    - тип голосования: одиночный, множественный, приоритетный;
    - срок голосования;
    - фильтры по жанрам, рейтингу, году, типу контента;
    - лимит предложений от одного участника;
    - флаг «Сравнить понравившиеся» (автоматический подбор фильмов из вишлистов участников).
- Предложение фильмов в комнату через поиск по каталогу.
- Голосование за предложенные фильмы.
- Просмотр результатов в реальном времени.
- Выход из комнаты, удаление комнаты создателем.

### 🔍 Тиндер-режим (в разработке)
- Свайп-интерфейс для поиска совпадений: пользователи лайкают или отклоняют фильмы.
- При совпадении лайков у нескольких участников фильм рекомендуется к просмотру.
- В текущей версии механика заложена на уровне базы данных (поле `matches`), но интерфейс находится в стадии доработки.

## Технологии

### Клиент (Android)
- **Язык:** Kotlin
- **UI:** XML, View Binding, Material Design
- **Архитектура:** Clean Architecture + MVVM
- **Сеть:** Retrofit, OkHttp, Gson
- **Навигация:** Jetpack Navigation Component, Safe Args
- **Асинхронность:** Kotlin Coroutines
- **Минимальная версия Android:** 8.0 (API 26)

### Сервер
- **Язык:** Kotlin
- **Фреймворк:** Ktor (CIO engine)
- **База данных:** MySQL + Exposed ORM
- **Аутентификация:** BCrypt
- **Веб-сервер:** Nginx (reverse proxy, TLS)
- **ORM:** Exposed
- **Пул соединений:** HikariCP

### Внешние сервисы
- **Кинопоиск API Unofficial** – данные о фильмах, рейтинги, постеры, актёры.

## Архитектура

Приложение построено по клиент-серверной архитектуре:

- **Клиент** (Android) общается с сервером по HTTPS, используя REST API и JSON.
- **Сервер** (Ktor) выполняет роль прокси: принимает запросы от клиента, проверяет JWT, обращается к внешнему API «Кинопоиск» с единым токеном, сохраняет пользовательские данные в MySQL.
- **База данных** хранит профили, друзей, списки фильмов, комнаты, голоса, оценки.

Схема базы данных включает 8 основных таблиц: `users`, `friendships`, `user_movie_list`, `user_ratings`, `room`, `room_members`, `room_suggestions`, `room_matches`.
